# KDS *(çalışma adı)*

SQLST ailesinin ikinci ürünü: web tabanlı, SaaS, self-servis raporlama ve karar destek
sistemi. Sürükle-bırak sorgu tasarımı + ham SQL + grafik/dashboard; .NET 10 + React +
Keycloak; hedef motor v1'de MSSQL.
